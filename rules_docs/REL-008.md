# REL-008: unhandled-webhook-error

## Metadata
- Rule ID: REL-008
- Category: Reliability
- Default Severity: MEDIUM

## Description
Webhook node has responseMode set to responseNode without downstream Respond to Webhook node.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Add a 'Respond to Webhook' node to guarantee clients receive an HTTP response.
