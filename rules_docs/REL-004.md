# REL-004: missing-execution-timeout

## Metadata
- Rule ID: REL-004
- Category: Reliability
- Default Severity: MEDIUM

## Description
Workflow has no explicit execution timeout configured, risking hanging workers on hung sockets.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Specify an executionTimeout (in seconds) under workflow settings (e.g. 300 to 3600 seconds).
