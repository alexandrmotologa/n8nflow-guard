# SEC-006: dangerous-command-injection

## Metadata
- Rule ID: SEC-006
- Category: Security
- Default Severity: HIGH

## Description
Execute Command node incorporates unparameterized expressions, posing a remote code execution risk.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Sanitize and validate all incoming inputs before concatenating them into shell commands.
