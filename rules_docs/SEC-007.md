# SEC-007: production-log-data-leak

## Metadata
- Rule ID: SEC-007
- Category: Security
- Default Severity: MEDIUM

## Description
Workflow persists all execution data on success in production, creating potential data leaks and DB bloat.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Set saveDataSuccessExecution to 'none' in workflow settings.
