# REL-003: unhandled-failure-continue

## Metadata
- Rule ID: REL-003
- Category: Reliability
- Default Severity: MEDIUM

## Description
Node continues on failure without dedicated error output connections or handling.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Ensure nodes using continueOnFail inspect error states in downstream nodes or use error triggers.
