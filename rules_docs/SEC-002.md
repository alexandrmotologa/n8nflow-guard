# SEC-002: unauthenticated-webhook

## Metadata
- Rule ID: SEC-002
- Category: Security
- Default Severity: HIGH

## Description
Webhook trigger is exposed to the public internet without authentication.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Configure authentication (headerAuth, basicAuth, or jwtAuth) in the webhook parameters.
