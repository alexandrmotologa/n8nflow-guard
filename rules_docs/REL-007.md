# REL-007: disabled-critical-node

## Metadata
- Rule ID: REL-007
- Category: Reliability
- Default Severity: MEDIUM

## Description
A disabled node is positioned between active connected nodes, breaking the execution chain.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Either re-enable the node, bypass its connections, or delete it from the canvas.

### Non-compliant Configuration

{

}
