# SEC-004: insecure-http-url

## Metadata
- Rule ID: SEC-004
- Category: Security
- Default Severity: MEDIUM

## Description
HTTP Request node transmits unencrypted data across the network using http:// protocol.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Update the URL protocol from http:// to https://.
