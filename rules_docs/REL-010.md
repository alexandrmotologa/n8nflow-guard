# REL-010: missing-conditional-fallback

## Metadata
- Rule ID: REL-010
- Category: Reliability
- Default Severity: MEDIUM

## Description
If or Switch node leaves one or more branch outputs completely unconnected without fallback handling.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Connect unhandled branches to a logging node or error alert to avoid silent drop of non-matching items.
