# SEC-001: hardcoded-secret

## Metadata
- Rule ID: SEC-001
- Category: Security
- Default Severity: CRITICAL

## Description
Detects hardcoded API keys, passwords, or high-entropy tokens in node parameters.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Move the sensitive value into an n8n credential vault or environment variable ({{ $env.VAR_NAME }}).

## Examples

### Non-compliant Configuration
```json
{
  "name": "Sample Node",
  "notes": "Non-compliant configuration exhibiting hardcoded-secret"
}
```

### Compliant Configuration
```json
{
  "name": "Sample Node",
  "notes": "Remediated configuration conforming to security standards"
}
```
