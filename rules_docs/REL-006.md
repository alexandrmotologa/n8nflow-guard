# REL-006: reference-to-missing-node

## Metadata
- Rule ID: REL-006
- Category: Reliability
- Default Severity: HIGH

## Description
Expression references a node name that does not exist in the current workflow.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Update the expression to reference an existing active node in the workflow canvas.

## Examples

### Non-compliant Configuration
```json
{
  "name": "Sample Node",
  "notes": "Non-compliant configuration exhibiting reference-to-missing-node"
}
```

### Compliant Configuration
```json
{
  "name": "Sample Node",
  "notes": "Remediated configuration conforming to security standards"
}
```
