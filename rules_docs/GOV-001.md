# GOV-001: missing-workflow-tags

## Metadata
- Rule ID: GOV-001
- Category: Governance
- Default Severity: LOW

## Description
Workflow is missing organizational taxonomy tags in version control.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Assign tags (e.g. environment, department, system) in n8n before exporting.

## Examples

### Non-compliant Configuration
```json
{
  "name": "Sample Node",
  "notes": "Non-compliant configuration exhibiting missing-workflow-tags"
}
```

### Compliant Configuration
```json
{
  "name": "Sample Node",
  "notes": "Remediated configuration conforming to security standards"
}
```
