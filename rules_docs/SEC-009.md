# SEC-009: unparameterized-sql-query

## Metadata
- Rule ID: SEC-009
- Category: Security
- Default Severity: HIGH

## Description
Database node interpolates raw expressions inside SQL strings, risking SQL injection.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Use parameterized queries ($1, $2 or :param) and n8n query parameters instead of raw string interpolation.
