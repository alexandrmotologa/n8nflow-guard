# SEC-008: permissive-cors-header

## Metadata
- Rule ID: SEC-008
- Category: Security
- Default Severity: MEDIUM

## Description
Webhook node sends a wildcard Access-Control-Allow-Origin: * CORS header.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Restrict the allowed origins to explicit trusted domain names.
