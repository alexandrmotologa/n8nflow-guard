# REL-009: missing-database-timeout

## Metadata
- Rule ID: REL-009
- Category: Reliability
- Default Severity: LOW

## Description
Database query node lacks explicit statement timeout configuration.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Configure query statement timeout options to prevent unindexed queries from locking connections.
