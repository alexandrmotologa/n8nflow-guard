# REL-011: unsafe-property-access

## Metadata
- Rule ID: REL-011
- Category: Reliability
- Default Severity: LOW

## Description
Detects deeply nested object property access without optional chaining (?.) risking runtime exceptions.

## Why It Matters
In n8n expressions, evaluating deeply nested keys such as `{{ $json.order.shipping.address.zip }}` throws unhandled JavaScript exceptions if any intermediate object is null or undefined, terminating execution prematurely.

## Remediation
Use optional chaining (e.g. `{{ $json.order?.shipping?.address?.zip }}`) to provide safe traversal through missing or variable payloads.

## Examples

### Non-compliant Configuration
```json
{
  "name": "Format Address",
  "parameters": {
    "zipCode": "={{ $json.customer.billing.address.zip }}"
  }
}
```

### Compliant Configuration
```json
{
  "name": "Format Address",
  "parameters": {
    "zipCode": "={{ $json.customer?.billing?.address?.zip }}"
  }
}
```
