# SEC-005: disabled-ssl-verification

## Metadata
- Rule ID: SEC-005
- Category: Security
- Default Severity: HIGH

## Description
HTTP Request node disables TLS/SSL certificate verification, exposing connections to man-in-the-middle attacks.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Remove allowUnauthorizedCerts or set it to false.
