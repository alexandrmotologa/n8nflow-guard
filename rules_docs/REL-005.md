# REL-005: malformed-expression

## Metadata
- Rule ID: REL-005
- Category: Reliability
- Default Severity: HIGH

## Description
Parameter contains an invalid or unclosed n8n expression syntax.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Correct mismatched braces or parenthesis in the expression.

## Examples

### Non-compliant Configuration
```json
{
  "name": "Sample Node",
  "notes": "Non-compliant configuration exhibiting malformed-expression"
}
```

### Compliant Configuration
```json
{
  "name": "Sample Node",
  "notes": "Remediated configuration conforming to security standards"
}
```
