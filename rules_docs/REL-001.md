# REL-001: missing-error-workflow

## Metadata
- Rule ID: REL-001
- Category: Reliability
- Default Severity: HIGH

## Description
Workflow has no global error handler workflow assigned, risking unnotified silent failures.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Set errorWorkflow in workflow settings to designate a dedicated incident response workflow.
