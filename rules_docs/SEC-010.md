# SEC-010: weak-cryptographic-hash

## Metadata
- Rule ID: SEC-010
- Category: Security
- Default Severity: MEDIUM

## Description
Crypto node employs deprecated hash algorithms such as MD5 or SHA1.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Switch to modern cryptographic hash functions such as SHA-256 or SHA-512.
