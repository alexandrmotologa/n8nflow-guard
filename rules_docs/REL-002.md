# REL-002: missing-retry-on-fail

## Metadata
- Rule ID: REL-002
- Category: Reliability
- Default Severity: MEDIUM

## Description
External network call node lacks retry-on-failure configuration for handling transient errors.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Enable retryOnFail and set maxTries to 3 or more with exponential backoff.
