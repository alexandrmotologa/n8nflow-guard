# SEC-003: plaintext-credential-object

## Metadata
- Rule ID: SEC-003
- Category: Security
- Default Severity: HIGH

## Description
Node contains inline plaintext credentials object instead of referencing an n8n credential ID.

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Link the node to a managed credential stored in the n8n credential store.
