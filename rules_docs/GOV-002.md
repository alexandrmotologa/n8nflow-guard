# GOV-002: missing-trigger-node

## Metadata
- Rule ID: GOV-002
- Category: Governance
- Default Severity: MEDIUM

## Description
Workflow has no entrypoint trigger node (webhook, schedule, poll, manual trigger).

## Why It Matters
Workflows in production handle customer data and sensitive integration points.
Violating this rule can result in unintended exposure, operational downtime, or runaway resource consumption.

## Remediation
Add a trigger node to ensure the workflow can receive invocation events.
